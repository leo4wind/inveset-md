# 还建议新增一个维度：投资流派

除了四层知识体系，我建议建立一个**正交分类**，把所有知识点映射到不同投资方法中，例如：

| 投资流派  | 核心名词                                  |
| ----- | ------------------------------------- |
| 价值投资  | 巴菲特、芒格、DCF、护城河、ROE、自由现金流、安全边际         |
| 指数投资  | ETF、指数基金、沪深300、标普500、定投、再平衡           |
| 量化投资  | 因子、Alpha、Beta、IC、RankIC、回测、Sharpe、CTA |
| 趋势投资  | MACD、均线、突破、趋势线、止损、仓位管理                |
| 宏观投资  | GDP、CPI、PMI、利率、美联储、美元指数               |
| 固收投资  | 国债、公司债、信用利差、久期、到期收益率                  |
| 衍生品投资 | 期货、期权、波动率、希腊字母、保证金                    |

这样，同一个术语（如 ETF）既属于 **L2 核心业务能力层**，也属于 **指数投资流派**；而 **夏普比率** 既属于 **L1 基础理论层**，又属于 **量化投资流派**。这种多维组织方式比单纯树状结构更贴近真实的知识网络。

## 学习优先级建议

如果你的目标是系统学习投资，而不是只会操作股票，我建议按以下顺序构建知识库：

1. **基础理论（约 40 个名词）**：收益、风险、复利、估值、市场机制。
2. **股票与 ETF（约 60 个名词）**：财报、估值指标、指数、基金、交易规则。
3. **宏观经济（约 30 个名词）**：利率、通胀、货币政策、经济周期。
4. **投资方法（约 50 个名词）**：价值投资、指数投资、成长投资、技术分析、量化投资。
5. **风险与行为金融（约 30 个名词）**：仓位管理、分散投资、认知偏差、投资纪律。

最终形成一个约 **200 个核心术语**的知识图谱，基本能够覆盖绝大多数投资书籍、券商研报、基金报告和财经新闻中出现的核心概念。
